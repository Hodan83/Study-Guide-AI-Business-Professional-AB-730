# AI Business Professional - Glossary

## A

**Accuracy**  
The proportion of correct predictions made by a model out of all predictions made.

**Algorithm**  
A set of step-by-step instructions or rules for solving a problem or completing a task.

**Anomaly Detection**  
The identification of unusual patterns or outliers in data that don't conform to expected behavior.

**Artificial Intelligence (AI)**  
The simulation of human intelligence processes by machines, especially computer systems, including learning, reasoning, and self-correction.

**Artificial Neural Network (ANN)**  
A computing system inspired by biological neural networks, consisting of interconnected nodes (neurons) that process information.

## B

**Backpropagation**  
An algorithm used to train neural networks by calculating gradients and adjusting weights to minimize error.

**Bias (Statistical)**  
Systematic error in AI predictions, often resulting from flawed assumptions in the learning algorithm or unrepresentative training data.

**Bias (Ethical)**  
Unfair or prejudiced outcomes in AI systems that disadvantage certain groups or individuals.

**Big Data**  
Extremely large datasets that can be analyzed computationally to reveal patterns, trends, and associations.

**Black Box Model**  
An AI model whose internal workings are not easily understood or explained, even if it produces accurate results.

## C

**Chatbot**  
A software application that conducts conversations with users through text or voice, often using NLP and AI.

**Classification**  
A supervised learning task where the model predicts categorical labels or classes for input data.

**Clustering**  
An unsupervised learning technique that groups similar data points together based on their characteristics.

**Computer Vision**  
A field of AI that enables computers to derive meaningful information from digital images, videos, and visual inputs.

**Convolutional Neural Network (CNN)**  
A type of deep learning network particularly effective for image recognition and computer vision tasks.

## D

**Data Mining**  
The process of discovering patterns and knowledge from large amounts of data.

**Data Preprocessing**  
The process of cleaning, transforming, and organizing raw data before feeding it to a machine learning model.

**Dataset**  
A collection of data used for training, validating, or testing machine learning models.

**Deep Learning (DL)**  
A subset of machine learning based on artificial neural networks with multiple layers (deep neural networks).

**Deployment**  
The process of making a machine learning model available for use in a production environment.

**Differential Privacy**  
A technique that adds noise to data to protect individual privacy while maintaining overall data utility.

## E

**Edge Computing**  
Processing data near the source (edge of the network) rather than in a centralized cloud, enabling faster AI inference.

**Ensemble Learning**  
A technique that combines multiple models to improve prediction accuracy and robustness.

**Epoch**  
One complete pass through the entire training dataset during the learning process.

**Ethics in AI**  
The study and application of moral principles to the design, development, and deployment of AI systems.

**Explainable AI (XAI)**  
AI systems designed to explain their decisions and actions in ways humans can understand.

## F

**Fairness**  
The principle that AI systems should treat all individuals and groups equitably without discrimination.

**False Negative**  
When a model incorrectly predicts the negative class (e.g., failing to detect fraud that exists).

**False Positive**  
When a model incorrectly predicts the positive class (e.g., flagging legitimate transaction as fraud).

**Feature**  
An individual measurable property or characteristic used as input to a machine learning model.

**Feature Engineering**  
The process of creating, selecting, and transforming features to improve model performance.

**Federated Learning**  
A machine learning approach where models are trained across multiple decentralized devices holding local data samples.

## G

**Generative AI**  
AI systems that can create new content, such as text, images, audio, or video, based on learned patterns.

**Governance (AI)**  
The framework of policies, procedures, and controls that ensure responsible and ethical use of AI systems.

**Gradient Descent**  
An optimization algorithm used to minimize the error in machine learning models by iteratively adjusting parameters.

## H

**Hyperparameter**  
A configuration setting that is set before training begins and controls the learning process.

**Hyperparameter Tuning**  
The process of finding optimal hyperparameter values to improve model performance.

## I

**Inference**  
The process of using a trained model to make predictions on new, unseen data.

**Internet of Things (IoT)**  
Network of physical devices embedded with sensors, software, and connectivity to collect and exchange data.

## K

**K-Means Clustering**  
An unsupervised learning algorithm that partitions data into K distinct clusters based on similarity.

**Key Performance Indicator (KPI)**  
A measurable value that indicates how effectively objectives are being achieved.

## L

**Label**  
The output or target value in supervised learning that the model is trying to predict.

**Labeled Data**  
Data that has been tagged with one or more labels to identify its characteristics or classification.

**Large Language Model (LLM)**  
A neural network trained on vast amounts of text data to understand and generate human language.

**Learning Rate**  
A hyperparameter that controls how much model weights are adjusted during training.

**LIME (Local Interpretable Model-agnostic Explanations)**  
A technique for explaining individual predictions of any machine learning model.

## M

**Machine Learning (ML)**  
A subset of AI that enables systems to learn and improve from experience without being explicitly programmed.

**Model**  
A mathematical representation that makes predictions or decisions based on input data.

**Model Drift**  
The degradation of model performance over time as the statistical properties of data change.

**Model Training**  
The process of teaching a machine learning model to make predictions by feeding it data and adjusting parameters.

## N

**Narrow AI (Weak AI)**  
AI systems designed to perform specific tasks, as opposed to general human-like intelligence.

**Natural Language Processing (NLP)**  
A branch of AI that helps computers understand, interpret, and generate human language.

**Neural Network**  
A computing system inspired by biological neural networks, consisting of interconnected nodes that process information.

## O

**Optical Character Recognition (OCR)**  
Technology that converts images of text into machine-readable text data.

**Overfitting**  
When a model learns training data too well, including noise, and performs poorly on new data.

**Overall Equipment Effectiveness (OEE)**  
A metric measuring manufacturing productivity based on availability, performance, and quality.

## P

**Precision**  
The proportion of positive predictions that are actually correct (true positives / (true positives + false positives)).

**Predictive Analytics**  
The use of data, statistical algorithms, and machine learning to identify the likelihood of future outcomes.

**Predictive Maintenance**  
Using AI to predict when equipment is likely to fail, enabling proactive maintenance.

**Pre-trained Model**  
A model that has been previously trained on a large dataset and can be fine-tuned for specific tasks.

## R

**Random Forest**  
An ensemble learning method that uses multiple decision trees to improve prediction accuracy.

**Recall (Sensitivity)**  
The proportion of actual positives that are correctly identified (true positives / (true positives + false negatives)).

**Recommendation System**  
An AI system that suggests products, content, or services to users based on their preferences and behavior.

**Regression**  
A supervised learning task where the model predicts continuous numerical values.

**Reinforcement Learning**  
A type of machine learning where an agent learns to make decisions by receiving rewards or penalties.

**Responsible AI**  
The practice of designing, developing, and deploying AI systems in a manner that is ethical, fair, and beneficial.

**Return on Investment (ROI)**  
A measure of the profitability of an investment, calculated as (Benefits - Costs) / Costs.

**Robotic Process Automation (RPA)**  
Technology that uses software robots to automate repetitive, rule-based tasks.

## S

**Scalability**  
The ability of a system to handle growing amounts of work or to expand capacity.

**Sentiment Analysis**  
The use of NLP to identify and extract subjective information, such as opinions and emotions, from text.

**SHAP (SHapley Additive exPlanations)**  
A method for explaining individual predictions by computing the contribution of each feature.

**Supervised Learning**  
A type of machine learning where models learn from labeled training data.

**Support Vector Machine (SVM)**  
A supervised learning algorithm used for classification and regression tasks.

## T

**Test Set**  
A portion of data used to evaluate the final performance of a trained model.

**Training Set**  
The portion of data used to train a machine learning model.

**Transfer Learning**  
A technique where a model trained on one task is adapted for use on a different but related task.

**Transparency**  
The principle that AI systems should be open about how they work and make decisions.

## U

**Underfitting**  
When a model is too simple to capture the underlying patterns in the data, resulting in poor performance.

**Unsupervised Learning**  
A type of machine learning where models find patterns in unlabeled data without predefined categories.

## V

**Validation Set**  
A portion of data used during training to tune hyperparameters and prevent overfitting.

**Virtual Assistant**  
An AI-powered application that can perform tasks or services based on voice or text commands.

## W

**Weight**  
A parameter in a neural network that determines the strength of connection between neurons.

## X

**XAI (Explainable AI)**  
See Explainable AI above.
