## 🎯 Study Approaches

### Approach 1: Sequential Learning
**Best for:** Beginners, comprehensive understanding

1. Module 1 → Module 2 → Module 3 → Module 4
2. Practice Questions after each module
3. Review Case Studies
4. Study Additional Resources
5. Final review with Glossary

**Timeline:** 8-12 weeks

### Approach 2: Topic-Based Learning
**Best for:** Those with some AI knowledge

1. Identify weak areas from Practice Questions
2. Study relevant modules
3. Deep dive into Case Studies
4. Review Additional Resources
5. Re-test with Practice Questions

**Timeline:** 4-6 weeks

### Approach 3: Exam-Focused Learning
**Best for:** Those with good AI foundation

1. Start with Practice Questions (full set)
2. Study only weak areas
3. Review all Case Studies
4. Quick scan of all modules
5. Final practice exam

**Timeline:** 2-4 weeks

## 💡 Study Tips

### Daily Routine
```
Morning (30 min):
- Review previous day's notes
- Read glossary terms

Lunch Break (30 min):
- Watch an AI video
- Read an article

Evening (1-2 hours):
- Study one section
- Complete practice questions
- Take notes
```

### Weekly Goals
- **Week 1:** Complete Module 1
- **Week 2:** Complete Module 2
- **Week 3:** Complete Module 3
- **Week 4:** Complete Module 4
- **Week 5:** Practice & Review

### Memory Techniques

**Acronyms:**
- **FAIR**: Fairness, Accountability, Interpretability, Reliability
- **DATA**: Define, Acquire, Train, Analyze

**Associations:**
- ML = Learning from data
- DL = Deep (many layers)
- NLP = Natural (human) Language

**Visual:**
- Draw the AI → ML → DL hierarchy
- Create mind maps for each module
